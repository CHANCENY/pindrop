Forms

Pindrop's FormBuilder generates HTML forms from a PHP array definition. It handles field rendering, validation state, file uploads, and fieldset grouping without writing HTML manually.

Defining a Form

A form is a PHP array where each key is the field name and the value is its configuration:

$form = [
    'title' => [
        'type'        => 'text',
        'title'       => 'Article Title',
        'placeholder' => 'Enter title...',
        'required'    => true,
        'value'       => '',
    ],
    'body' => [
        'type'        => 'textarea',
        'title'       => 'Content',
        'rows'        => 10,
        'placeholder' => 'Write your content...',
    ],
    'category' => [
        'type'    => 'select',
        'title'   => 'Category',
        'options' => [
            ['value' => 'news',  'label' => 'News'],
            ['value' => 'tech',  'label' => 'Technology'],
            ['value' => 'other', 'label' => 'Other'],
        ],
    ],
    'published' => [
        'type'  => 'checkbox',
        'title' => 'Publish immediately',
        'value' => false,
    ],
    'cover_image' => [
        'type'   => 'file',
        'title'  => 'Cover Image',
        'accept' => 'image/*',
    ],
];

Building and Rendering

use Simp\Pindrop\Form\FormBuilder;
use Simp\Pindrop\Form\FormState;

$formState = new FormState();
$formState->buildFormState($form, $request);

$builder = new FormBuilder();
$builder->buildFormRender($form, $formState, $request);

// Cast to string to get the HTML
$formHtml = (string) $builder;

// Pass to Twig
return $this->renderTwig('my_plugin/create.twig', [
    'form_html' => $formHtml,
]);
{# In your Twig template #}

Handling Submission

public function create(Request $request, string $route_name, array $options): Response
{
    $form = $this->buildMyForm();
    $formState = new FormState();
    $formState->buildFormState($form, $request);

    if ($request->isMethod('POST')) {
        $title = $formState->getValue('title');
        $body  = $formState->getValue('body');

        // Validate
        if (empty($title)) {
            $formState->setErrorByName('title', 'Title is required');
        }

        if ($formState->isValidated()) {
            // Process the valid form
            // ... save to DB etc.
            return $this->redirect('/my-plugin/list');
        }
    }

    $builder = new FormBuilder();
    $builder->buildFormRender($form, $formState, $request);

    return $this->renderTwig('my_plugin/create.twig', [
        'form_html' => (string) $builder,
    ]);
}

Auto-generated forms

Entity forms are auto-generated by StorageEntity::getEntityForm() based on fieldDefinitions(). You only need to build forms manually for custom workflows that aren't content entities.

File Upload Handling

When a form contains a file or image field, FormBuilder automatically injects a JavaScript upload widget. The form must be rendered inside an HTML page that does not suppress scripts. The upload field posts as a standard multipart file.

// In controller after POST
$file = $request->files->get('cover_image');

if ($file && $file->isValid()) {
    $fs = getAppContainer()->get('filesystem');
    $dest = 'public://uploads/' . uniqid() . '.' . $file->getClientOriginalExtension();

    $result = $fs->uploadFile([
        'name'     => $file->getClientOriginalName(),
        'tmp_name' => $file->getPathname(),
        'size'     => $file->getSize(),
        'error'    => $file->getError(),
    ], $fs->resolvedRealPath($dest), [
        'unique'        => true,
        'allowed_types' => ['jpg', 'jpeg', 'png', 'gif', 'webp'],
    ]);

    if ($result['success']) {
        $fileUri = $dest; // store this in your entity
    }
}
