Users

The User entity (pindrop/Entity/User/User.php) is the core user object in Pindrop. It supports roles, statuses, 2FA fields, login tracking, email verification, and soft deletion. User management in the admin UI is provided by the admin plugin.

---

Creating a User (PHP)

Create and save a user programmatically from a controller or service:

use Simp\Pindrop\Entity\User\User;

$db = getAppContainer()->get('database');

$user = new User([], $db);
$user->setUsername('johndoe');
$user->setEmail('john@example.com');
$user->setPassword('plaintext-password'); // hashed automatically
$user->setRole(User::ROLE_USER);
$user->setStatus(User::STATUS_ACTIVE);
$user->setCreatedAt(new DateTime());

if ($user->save()) {
    echo 'User created with ID: ' . $user->getId();
}
setPassword() automatically generates a salt and hashes the password using password_hash(PASSWORD_DEFAULT). Never set passwordHash directly unless you are importing a pre-hashed value.
---

Loading Users (PHP)

// Load by ID
$user = User::loadById(42, $db);

// Load by email
$user = User::loadByEmail('john@example.com', $db);

// Load by username
$user = User::loadByUsername('johndoe', $db);

// Load all users
$users = User::loadAll($db);

// Paginated load (for listing pages)
$page = User::loadWithPagination(1, 20, $db);
// $page['users'], $page['total'], $page['total_pages']
---

Updating a User (PHP)

$user = User::loadById(42, $db);

$user->setEmail('newemail@example.com');
$user->setRole(User::ROLE_ADMIN);
$user->setStatus(User::STATUS_ACTIVE);

// Change password
$user->setPassword('new-plaintext-password');

$user->save();
---

Deleting a User (PHP)

$user = User::loadById(42, $db);
$user->delete();
Only super_admin users can delete users through the admin UI (admin.users.delete route). Deletion via PHP is not role-restricted — apply your own access checks when calling delete() from custom code.

Admin UI — User Management

The admin plugin provides a full user management interface under /admin/users. All routes require admin or super_admin role unless noted.

URLWhat it doesRole required
/admin/usersPaginated list of all usersadmin, super_admin

Importing Users

Users can be bulk-imported from a .csv, .xlsx, or .xls file. Download the template at /admin/users/import-template. The import accepts the following columns:

ColumnRequiredNotes
usernameYesMust be unique
emailYesMust be a valid, unique email
first_nameNo
last_nameNo
roleNoDefaults to user. Valid: user, moderator, admin, super_admin
statusNoDefaults to pending. Valid: pending, active, inactive

Import options available in the UI: skip duplicates, send welcome email, require password reset on first login.
