Installation

This guide will walk you through installing and setting up Pindrop CMS.

---

1. Download Pindrop

Download the latest release from the official repository:

https://github.com/CHANCENY/pindrop
---

2. Install Dependencies

Run Composer to install required packages:

composer install
---

3. (Optional) Lando Setup

If you are using lando, update your project name inside:

.lando.yml
---

4. Environment Configuration

Copy the example environment file and rename it: 

cp .env.example .env

Then edit .env and configure:

  • Database credentials
  • ROOT → Root path of your project
---

5. Make CLI Executable

chmod +x pindro
---

6. Run Installation Command

If using Lando:

lando ssh

Then inside the container:

./pindro db:schema:create

You will be prompted with a question. Enter:

0

Then press Enter.

---

7. Access Your Application

Once installation is complete, open your application in the browser.

---

Important Notes

  • To fully use the application, you must install and enable the admin plugin.
  • See the plugins documentation:
    Plugins Guide
  • For ./pindro db:schema:create to work, you must install and enable the terminal_command plugin.
---

You're Ready

Your Pindrop CMS installation is now complete. You can proceed with installing plugins and building your system.
