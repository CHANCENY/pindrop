Getting Started

Installation

This guide walks through a complete Pindrop installation from source — dependencies, environment, database, and mandatory plugins.

Prerequisites

  • PHP 8.1+ with extensions: pdo, pdo_mysql, zip, dom, libxml
  • MySQL 5.7+ or MariaDB 10.3+
  • Composer 2.x
  • Apache with mod_rewrite, or Nginx with equivalent rewrites
  • Git (for downloading plugins)

Steps

  1. 1
    Download Pindrop

    Clone or download from the official repository

git clone https://github.com/CHANCENY/pindrop.git my-site
cd my-site
  1. 2
    Install Composer dependencies
composer install
  1. 3
    Configure environment

    Copy and edit the example env file

cp .env.example .env

Open .env and set at minimum:

ROOT="/absolute/path/to/my-site"
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=pindrop_db
DB_USERNAME=db_user
DB_PASSWORD=db_pass
APP_ENV=development
DEBUG=TRUE
  1. 4
    Optional: Lando setup

    If using Lando, edit the project name in .lando.yml then run lando start

  2. 5
    Make CLI executable
chmod +x pindro
  1. 6
    Install mandatory plugins
# Download from official plugin repo
./pindro plugin:download terminal_command
./pindro plugin:download admin

# Register and enable both
./pindro plugin:install terminal_command && ./pindro plugin:enable terminal_command
./pindro plugin:install admin           && ./pindro plugin:enable admin
  1. 7
    Create database tables

    Run the schema creation command and enter 0 when prompted (creates ALL tables)

./pindro db:schema:create
# When asked "Which schema do you wish to create?" → enter 0 → press Enter
  1. 8
    Open in browser

    Navigate to your configured URL. Register at /user/register to create your first account.

First super admin

New accounts get role user by default. Manually set the first account to super_admin in the database:
UPDATE users SET role='super_admin' WHERE id=1;
Then log in and manage all future roles via the admin UI at /admin/users.

Important Notes

Admin plugin required

The admin plugin provides the login page, admin dashboard, user management, and content management. Without it the CMS has no UI.

terminal_command plugin required

The terminal_command plugin provides db:schema:create and other CLI commands. Without it you cannot create the database tables.

You're Ready

Your Pindrop installation is complete. Next steps:

  • Install additional plugins from github.com/CHANCENY/pindrop-features
  • Create your first custom plugin — see Plugin System
  • Build your first content type — see Entities
