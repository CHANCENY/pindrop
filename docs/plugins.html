Plugins

Plugins are the building blocks of Pindrop. Every feature is delivered as a plugin stored as a branch in the official plugin repository. Installing a plugin is cloning a branch into modules/.

Key concept

Each branch in github.com/CHANCENY/pindrop-features is one plugin. The branch name is the plugin ID.

Downloading a Plugin

# Via CLI (recommended — handles placement automatically)
./pindro plugin:download admin

# Or manually with git
git clone -b admin --single-branch https://github.com/CHANCENY/pindrop-features.git modules/admin

Installing & Enabling

# Install (registers in config/sync/core.plugin.yml)
./pindro plugin:install admin

# Enable
./pindro plugin:enable admin

# View status of all plugins
./pindro plugins

Disabling & Uninstalling

# Disable (plugin stays on disk, just won't load)
./pindro plugin:disable my_plugin

# Uninstall (deregisters from config)
./pindro plugin:uninstall my_plugin

# Remove completely (uninstall + delete files)
./pindro plugin:remove my_plugin

Config File

Plugin state is stored in config/sync/core.plugin.yml:

admin: 1               # installed + enabled
terminal_command: 1    # installed + enabled
my_plugin: 0           # installed but disabled
ValueMeaning
1Installed and enabled — plugin loads on every request
0Installed but disabled — plugin exists on disk but won't load
(absent)Not registered — PluginManager ignores it even if files exist

Naming Rules

  • Lowercase only
  • Use underscores, not hyphens: my_plugin not my-plugin
  • Branch name = folder name = config key — all three must match exactly

Admin UI Plugin Management

Navigate to /admin/plugins (requires admin or super_admin role) to install, enable, disable, configure, and upload plugin ZIPs from the browser.
