Content Entities

Content entities are the data objects you store in Pindrop — articles, pages, products, and any custom content type you define. Each entity type is a PHP class that extends StorageEntity and is registered with the system via entity.repository.yml inside a plugin.

Two-table design: Every entity type uses two database tables. The node_data core table stores universal fields (title, status, author, timestamps, etc.). Your entity's custom table (defined in fieldDefinitions()) stores entity-specific fields as serialised JSON in a field_data column.
---

Creating an Entity Class

Place your entity class inside your plugin's src/Entity/ directory and extend StorageEntity. You only need to implement two methods: fieldDefinitions() and getView(). 

<?php

namespace Simp\Pindrop\Modules\my_plugin\src\Entity;

use Simp\Pindrop\Content\Storage\StorageEntity;

class Article extends StorageEntity
{
    public function fieldDefinitions(): array
    {
        return [
            'table'            => 'content_articles',   // your custom table name
            'reference_field'  => 'entity_id',          // FK column linking to node_data
            'data_field'       => 'field_data',          // JSON column for your fields
            'fields' => [
                'category' => [
                    'type'     => 'string',
                    'required' => false,
                    'default'  => 'general',
                ],
                'tags' => [
                    'type'     => 'array',
                    'required' => false,
                    'default'  => [],
                ],
                'featured_image' => [
                    'type'     => 'string',
                    'required' => false,
                ],
                'reading_time' => [
                    'type'     => 'integer',
                    'required' => false,
                    'default'  => 0,
                ],
            ],
        ];
    }

    public function getView(): string
    {
        return getAppContainer()->get('twig')
            ->render('@my_plugin/content/article.twig', ['entity' => $this]);
    }
}

Registering an Entity

After creating the class, register it in your plugin's entity.repository.yml: 

article:
  class: Simp\Pindrop\Modules\my_plugin\src\Entity\Article
  description: "Article content entity"
  category: "content"
  version: "1.0"

The key (article) becomes the entity's machine name used across the system — in routes, the content factory, and the admin UI.

---

Creating Schema

Your entity needs its custom table created in the database. Define a MySQL schema file in your plugin (e.g. modules/my_plugin/mysql/content_articles.sql) and run: 

./pindro db:schema:create

Select your table from the list or choose ALL to create every registered schema.

Creating Content (PHP)

$factory = getAppContainer()->get('content.factory');

// Get an entity instance by machine name
$article = $factory->storage('article');

$article->setTitle('My First Article');
$article->setContent('<p>Article body here.</p>');
$article->setStatus('published');
$article->setPublished(true);
$article->setPublishedAt(new DateTime());
$article->setAuthorId(getAppContainer()->get('current_user')->getId());

// Set entity-specific custom fields
$article->setValue('category', 'technology');
$article->setValue('tags', ['php', 'cms']);
$article->setValue('reading_time', 5);

// Timestamps
$article->setCreatedAt(new DateTime());
$article->setUpdatedAt(new DateTime());

if ($article->save()) {
    echo 'Created with ID: ' . $article->getId();
}
---

Loading Content (PHP)

// By ID (auto-detects type)
$repository = getAppContainer()->get('content.repository');
$entity = $repository->find(42);

// By type — static method on entity class
use Simp\Pindrop\Modules\my_plugin\src\Entity\Article;

$article = Article::load(42);         // single by ID
$articles = Article::all();           // all records
$count = Article::count();            // total count

// Filter
$results = Article::filter([
    'status' => 'published',
], ['limit' => 10, 'page' => 1]);
---

Updating Content (PHP)

$repository = getAppContainer()->get('content.repository');
$entity = $repository->find(42);

$entity->setTitle('Updated Title');
$entity->setStatus('draft');
$entity->setValue('category', 'news');
$entity->setUpdatedAt(new DateTime());

$entity->save();
---

Deleting Content (PHP)

$article = Article::load(42);
Article::delete(42);

Admin UI — Content Management

URLWhat it does
/admin/contentList all content across all registered entity types
/admin/content/createPick a content type to create
/admin/content/{type}/addCreate content of a given type using the entity's auto-generated form
/admin/content/{id}/editEdit an existing content item
/content/{id}Public/admin view of a single content item (renders getView())
The add/edit form is auto-generated from fieldDefinitions() via getEntityForm() on StorageEntity. You do not need to write a Twig form manually — the framework builds it from your field declarations.
