Events System

Pindrop's event system is a lightweight publish-subscribe mechanism. Core framework actions fire named events. Plugins subscribe to events by declaring an EventsSubscriber class and receive a mutable EventEmitter object they can inspect and modify.

How It Works

On bootstrap, EventsManager scans every enabled plugin for an Events.php constants class and an EventsSubscriber.php subscriber. Both files must live at src/Plugin/Events/ inside the plugin directory.

modules/my_plugin/
└── src/
    └── Plugin/
        └── Events/
            ├── Events.php           ← declare custom event constants
            └── EventsSubscriber.php ← subscribe to events

Declaring Custom Events

<?php
// modules/my_plugin/src/Plugin/Events/Events.php

namespace Simp\Pindrop\Modules\my_plugin\src\Plugin\Events;

class Events
{
    public const string ORDER_PLACED    = 'my_plugin.order.placed';
    public const string ORDER_FULFILLED = 'my_plugin.order.fulfilled';
    public const string PAYMENT_FAILED  = 'my_plugin.payment.failed';
}

Subscribing to Events

<?php
// modules/my_plugin/src/Plugin/Events/EventsSubscriber.php

namespace Simp\Pindrop\Modules\my_plugin\src\Plugin\Events;

use Simp\Pindrop\Events\EventEmitter;
use Simp\Pindrop\Events\EventsSubscriberInterface;
use Simp\Pindrop\Events\SystemEvents\Events as SystemEvents;

class EventsSubscriber implements EventsSubscriberInterface
{
    public function getSubscribedEvents(): array
    {
        return [
            // System events
            SystemEvents::ENTITY_CREATED   => [self::class, 'onEntityCreated'],
            SystemEvents::AUTH_LOGIN        => [self::class, 'onLogin'],

            // Custom events
            Events::ORDER_PLACED => [self::class, 'onOrderPlaced'],
        ];
    }

    public static function onEntityCreated(EventEmitter &$event): void
    {
        // $event->entity is the newly-created StorageEntity
        $entity = $event->entity ?? null;
        if ($entity) {
            // e.g. clear a cache, send a notification
        }
    }

    public static function onLogin(EventEmitter &$event): void
    {
        $user = $event->user ?? null;
        // log login analytics, update last_seen, etc.
    }

    public static function onOrderPlaced(EventEmitter &$event): void
    {
        $order = $event->order ?? null;
        // send confirmation email, update inventory, etc.
    }
}
EventEmitter is passed by reference

Subscriber methods receive EventEmitter &$event by reference. Setting properties on $event modifies the data returned to the caller — this is how subscribers can mutate event payloads (e.g. enrich an entity before it is saved).

Firing Events

// Using the global helper (available everywhere after bootstrap)
$results = appEvents()->invokeEvents(
    Events::ORDER_PLACED,
    ['order' => $orderObject, 'user' => $userObject]
);

// $results contains the (potentially modified) arguments after all listeners ran

Firing Events from a Controller

use Simp\Pindrop\Events\SystemEvents\Events;

// After creating an entity
appEvents()->invokeEvents(Events::ENTITY_CREATED, ['entity' => $entity]);

// After a password reset
appEvents()->invokeEvents(Events::AUTH_PASSWORD_RESET, ['user' => $user]);
Naming convention

Prefix custom event names with your plugin ID to avoid clashes with other plugins: my_plugin.some_event. Use dots as separators, not underscores.
