Core

Mail

Pindrop's MailManager wraps PHPMailer and is configured via environment variables. It supports plain text, HTML, attachments, CC/BCC, reply-to, and batch sending out of the box.

SMTP Configuration

All mail settings are read from .env:

SMTP_HOST=smtp.example.com
SMTP_PORT=465
SMTP_USER=noreply@example.com
SMTP_PASS=your-smtp-password
SMTP_SECURE=ssl          # ssl or tls
SMTP_DEBUG=0             # 0=off, 1=client, 2=server
MAIL_FROM_EMAIL=noreply@example.com

Accessing the Mail Service

$mailer = getAppContainer()->get('mail');

Sending Emails

Plain text

$mailer->sendText('user@example.com', 'Welcome!', 'Thanks for registering.');

HTML email

$html = '<h1>Welcome</h1><p>Thanks for joining <strong>Pindrop</strong>.</p>';
$mailer->sendHtml('user@example.com', 'Welcome!', $html, strip_tags($html));

With attachment

$mailer->sendWithAttachment(
    'user@example.com',
    'Your Invoice',
    '<p>Please find your invoice attached.</p>',
    '/path/to/invoice.pdf',
    'invoice-2024.pdf'   // optional custom filename
);

Full options

$mailer->send(
    'recipient@example.com',
    'Subject Line',
    '<p>HTML body</p>',
    [
        'html'     => true,
        'cc'       => ['cc@example.com'],
        'bcc'      => ['bcc@example.com'],
        'reply_to' => 'support@example.com',
        'headers'  => ['X-Custom-Header' => 'value'],
        'attachments' => [
            '/absolute/path/to/file.pdf',
            ['path' => '/another/doc.xlsx', 'name' => 'report.xlsx'],
        ],
    ]
);

Batch Sending

$messages = [
    [
        'to'      => 'alice@example.com',
        'subject' => 'Hello Alice',
        'body'    => '<p>Hi Alice!</p>',
        'options' => ['html' => true],
    ],
    [
        'to'      => 'bob@example.com',
        'subject' => 'Hello Bob',
        'body'    => '<p>Hi Bob!</p>',
        'options' => ['html' => true],
    ],
];

$results = $mailer->sendMultiple($messages);
// $results is an array of ['to', 'subject', 'success'] per message

Testing the Connection

if ($mailer->testConnection()) {
    echo 'SMTP is reachable';
} else {
    echo 'Error: ' . $mailer->getLastError();
}

MailManager Methods

MethodDescription
send(to, subject, body, options)Full-featured send with all options
sendText(to, subject, message)Plain text shortcut
sendHtml(to, subject, html, text)HTML with plain text fallback
sendWithAttachment(to, subject, body, path, name)Single attachment shortcut
sendMultiple(array)Batch send, returns per-message results
testConnection()Test SMTP connectivity
validateEmail(string)Validate an email address format
setFrom(email, name)Override the From address at runtime
setDebug(bool)Toggle SMTP debug output
getLastError()Get the most recent PHPMailer error string
getStatistics()Return config + status summary array
getMailer()Get raw PHPMailer instance for advanced use

Using in a Plugin Service

# services.yml
my_plugin.notifier:
  class: Simp\Pindrop\Modules\my_plugin\src\Services\NotifierService
  arguments:
    - "@mail"
    - "@logger"
<?php

class NotifierService
{
    public function __construct(
        private \Simp\Pindrop\Mail\MailManager $mailer,
        private \Simp\Pindrop\Logger\LoggerInterface $logger
    ) {}

    public function welcomeEmail(string $to, string $name): bool
    {
        $html = "<h1>Welcome, {$name}!</h1><p>Your account is ready.</p>";

        $sent = $this->mailer->sendHtml($to, "Welcome to Pindrop", $html);

        if (!$sent) {
            $this->logger->error("Welcome email failed", ['to' => $to]);
        }

        return $sent;
    }
}
Localhost / development

In development without a real SMTP server, use Mailpit or Mailtrap. Point SMTP_HOST and SMTP_PORT at your local mail catcher.
