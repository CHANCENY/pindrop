Getting Started

Quick Start

From zero to a running Pindrop CMS in under 10 minutes. This guide covers installation, database setup, mandatory plugins, and creating your first custom plugin.

Prerequisites

Make sure you have these available before starting:

  • PHP 8.1 or higher with extensions: pdo, pdo_mysql, zip, dom, libxml
  • MySQL 5.7+ or MariaDB 10.3+
  • Composer 2.x
  • Apache with mod_rewrite enabled (or Nginx with equivalent rewrite rules)
  • Git (for downloading plugins)

Step-by-Step Installation

  • 1
    Clone or download the repository

    Get the Pindrop source from github.com/CHANCENY/pindrop

  • 2
    Install Composer dependencies 
composer install
  • 3
    Create and configure your .env file 
cp .env.example .env

Edit .env and set at minimum:

ROOT="/absolute/path/to/your/project"
DB_HOST=127.0.0.1
DB_DATABASE=my_database
DB_USERNAME=my_user
DB_PASSWORD=secret
APP_ENV=development
DEBUG=TRUE
  • 4
    Create the database 
mysql -u root -p -e "CREATE DATABASE my_database CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
  • 5
    Download and enable mandatory plugins 
chmod +x pindro

# Download both mandatory plugins
./pindro plugin:download terminal_command
./pindro plugin:download admin

# Install and enable them
./pindro plugin:install terminal_command
./pindro plugin:enable terminal_command
./pindro plugin:install admin
./pindro plugin:enable admin
  • 6
    Create all database tables 
./pindro db:schema:create
# When prompted, enter 0 (or select ALL) and press Enter
  • 7
    Open the app in your browser

    Navigate to your site URL. You should see the Pindrop home page. Go to /user/register to create the first admin account, then visit /admin.

First admin account

Register via /user/register. The first user will have role user by default. Manually update the role to super_admin in the database: UPDATE users SET role='super_admin' WHERE id=1; — then log in and manage all future roles from the admin UI.

Your First Plugin

Create a new plugin interactively:

./pindro plugin:create
# Enter: name, description, version, author, website, license

This scaffolds the plugin directory with all YAML files. Then install and enable it:

./pindro plugin:install my_plugin
./pindro plugin:enable my_plugin

Add a route

# modules/my_plugin/routing.yml
my_plugin.hello:
  path: '/hello'
  methods: ['GET']
  defaults:
    _controller: 'Simp\Pindrop\Modules\my_plugin\src\Controller\HelloController::index'
  requirements: {}

Add a controller

<?php
// modules/my_plugin/src/Controller/HelloController.php

namespace Simp\Pindrop\Modules\my_plugin\src\Controller;

use Simp\Pindrop\Controller\ControllerBase;
use Symfony\Component\HttpFoundation\Request;
use Symfony\Component\HttpFoundation\Response;

class HelloController extends ControllerBase
{
    public function index(Request $request, string $route_name, array $options): Response
    {
        return $this->render('<h1 style="font-family:sans-serif;padding:40px">Hello from my plugin!</h1>');
    }
}

Visit /hello in your browser. You should see your message.
