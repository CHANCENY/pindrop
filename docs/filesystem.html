Core

File System

Pindrop uses stream wrappers for file operations. The public:// protocol maps to your publicly accessible files directory. All upload, read, write, and delete operations go through FileSystem so path resolution is consistent across environments.

Configuration

PUBLIC_STREAM=public://
PUBLIC_STREAM_DIR=[ROOT]/sites/default/files

Any URI beginning with public:// resolves to a real path under PUBLIC_STREAM_DIR. For example, public://content/2024/06/photo.jpg maps to /app/sites/default/files/content/2024/06/photo.jpg.

Accessing the Service

$fs = getAppContainer()->get('filesystem');

Core Operations

// Check if a file exists
if ($fs->exists('public://uploads/logo.png')) { ... }

// Read file contents
$content = $fs->read('public://templates/email.html');

// Write / create a file (creates parent dirs automatically)
$fs->write('public://exports/report.csv', $csvContent);

// Append to a file
$fs->write('public://logs/audit.log', $line, FILE_APPEND);

// Delete a file
$fs->delete('public://uploads/old-photo.jpg');

// Copy
$fs->copy('public://originals/img.jpg', 'public://thumbnails/img.jpg');

// Move / rename
$fs->move('public://tmp/upload_xyz', 'public://content/2024/06/photo.jpg');

// List directory contents
$files = $fs->listDirectory('public://content/2024/06/');

// Resolve to real path (for use with PHP file functions)
$realPath = $fs->resolvedRealPath('public://content/2024/06/');
// → /app/sites/default/files/content/2024/06/

Uploading Files

$uploadedFile = $request->files->get('photo');

if ($uploadedFile && $uploadedFile->isValid()) {

    $ext  = $uploadedFile->getClientOriginalExtension();
    $dest = 'public://content/' . date('Y/m') . '/' . uniqid() . '.' . $ext;

    $result = $fs->uploadFile(
        [
            'name'     => $uploadedFile->getClientOriginalName(),
            'tmp_name' => $uploadedFile->getPathname(),
            'size'     => $uploadedFile->getSize(),
            'error'    => $uploadedFile->getError(),
        ],
        $fs->resolvedRealPath($dest),
        [
            'unique'        => true,           // append suffix if name collides
            'allowed_types' => ['jpg', 'jpeg', 'png', 'gif', 'webp', 'pdf'],
        ]
    );

    if ($result['success']) {
        $fileUri  = $dest;                          // store this
        $mimeType = $result['data'][0]['mime_type'];
        $size     = $result['data'][0]['size'];
    } else {
        // $result['message'] has the error
    }
}

The File Entity

When a file is uploaded as part of content management, a File entity record is created in the files database table. This links the file to its owning entity and tracks metadata.

use Simp\Pindrop\Entity\File\File;

$db = getAppContainer()->get('database');

// Load by ID
$file = File::loadById(10, $db);

// Load by URI
$file = File::loadByUri('public://content/2024/06/photo.jpg', $db);

echo $file->getFilename();   // original filename
echo $file->getUri();        // public:// URI
echo $file->getFilemime();   // MIME type
echo $file->getFilesize();   // bytes
echo $file->getStatus();     // permanent | temporary
public:// is the only registered wrapper

Only the public:// stream wrapper is registered by default. All user-uploaded files must go through this wrapper. Private or protected file storage is not built in — implement it as a plugin if needed.
