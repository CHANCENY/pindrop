Tools

CLI (pindro)

The pindro CLI tool is the command-line interface for Pindrop. It provides commands for database management, plugin operations, and system information. Commands are loaded from plugins via pindro.commands.yml.

Setup

chmod +x pindro
./pindro <command>

The CLI requires the terminal_command plugin to be installed and enabled. It bootstraps the full application including the DI container, so all services are available inside command functions.

Writing Custom Commands

Declare a pindro.commands.yml in your plugin, then create a PHP script that returns an array mapping command names to function names.

1. pindro.commands.yml

my_plugin.commands:
  name: "My Plugin Commands"
  script: "modules/my_plugin/cli/commands.php"
  status: true

2. cli/commands.php

<?php

return [
    'my_plugin:sync'  => 'myPluginSync',
    'my_plugin:stats' => 'myPluginStats',
    'my_plugin:clean' => 'myPluginClean',
];

function myPluginSync(CLIPrinter $printer, string $command, array $argv): void
{
    $printer->printLine("Starting sync...", YELLOW);

    $db = getAppContainer()->get('database');
    // ... do work ...

    $printer->printLine("Sync complete.", GREEN);
}

function myPluginStats(CLIPrinter $printer, string $command, array $argv): void
{
    $rows = [
        ['Metric', 'Value'],
        ['Users',    '142'],
        ['Articles', '38'],
        ['Files',    '97'],
    ];
    $printer->printTable($rows, [GREEN, GREEN]);
}

function myPluginClean(CLIPrinter $printer, string $command, array $argv): void
{
    // Interactive confirmation
    $confirm = $printer->ask("Type YES to confirm cleanup:", "");
    if ($confirm !== 'YES') {
        $printer->printLine("Aborted.", RED);
        return;
    }

    // ... clean up ...
    $printer->printLine("Done.", GREEN);
}

CLIPrinter Methods

MethodDescription
printLine(string $text, string $color)Print a coloured line. Colors: GREEN, RED, YELLOW, BLUE
printTable(array $rows, array $colors)Print a formatted ASCII table. First row is the header.
ask(string $question, string $default, callable $validator)Prompt for user input with optional default and validation callback
askChoice(string $question, array $choices, mixed $default)Prompt user to select from a numbered list

Accessing Arguments

// Command: ./pindro my_plugin:sync --force --env=production extra_arg
// $argv = ['pindro', 'my_plugin:sync', '--force', '--env=production', 'extra_arg']

function myPluginSync(CLIPrinter $printer, string $command, array $argv): void
{
    $force = in_array('--force', $argv);

    // Extract named arg
    $env = null;
    foreach ($argv as $arg) {
        if (str_starts_with($arg, '--env=')) {
            $env = substr($arg, 6);
        }
    }

    // Positional args after command name
    $extras = array_slice($argv, 2); // ['--force', '--env=production', 'extra_arg']
}
Full DI container available

Inside any CLI command function you have access to the full DI container via getAppContainer(). All services — database, logger, mail, filesystem, plugin manager — are available exactly as they are in HTTP controllers.

Running inside Lando

If using Lando for local development, SSH into the container first: lando ssh, then run ./pindro <command>.
