Controllers

Controllers are the bridge between routes and responses. Every HTTP route maps to a controller method that receives the request and returns a Symfony Response object.

Creating a Controller

Extend ControllerBase and place your class in your plugin's src/Controller/ directory.

<?php

namespace Simp\Pindrop\Modules\my_plugin\src\Controller;

use Simp\Pindrop\Controller\ControllerBase;
use Symfony\Component\HttpFoundation\Request;
use Symfony\Component\HttpFoundation\Response;

class MyController extends ControllerBase
{
    public function index(Request $request, string $route_name, array $options): Response
    {
        return $this->renderTwig('my_plugin/home.twig', [
            'page_title' => 'Home',
        ]);
    }

    public function show(Request $request, string $route_name, array $options): Response
    {
        $id = $request->query->get('id');
        return $this->renderTwig('my_plugin/show.twig', ['id' => $id]);
    }
}
Method signature

Every controller method receives exactly three arguments: Request $request, string $route_name, and array $options. Path parameters (e.g. [id:int]) arrive in $options.

Registering in routing.yml

my_plugin.index:
  path: '/items'
  methods: ['GET']
  defaults:
    _controller: 'Simp\Pindrop\Modules\my_plugin\src\Controller\MyController::index'
  requirements:
    _permission: ['user', 'admin', 'super_admin']

my_plugin.show:
  path: '/items/[id:int]'
  methods: ['GET']
  defaults:
    _controller: 'Simp\Pindrop\Modules\my_plugin\src\Controller\MyController::show'
  requirements:
    _permission: ['user', 'admin', 'super_admin']

Reading Request Data

// Query string: /items?page=2&limit=10
$page  = $request->query->get('page', 1);
$limit = $request->query->get('limit', 20);

// POST body
$data = $request->request->all();
$name = $request->request->get('name');

// Uploaded files
$file = $request->files->get('avatar');

// Path params from route e.g. /items/[id:int]
$id = $request->query->get('id');  // resolved by router

// Headers
$accept = $request->headers->get('Accept');

// HTTP method check
if ($request->isMethod('POST')) { /* ... */ }

// Client IP
$ip = $request->getClientIp();

Returning Different Response Types

use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\HttpFoundation\JsonResponse;
use Symfony\Component\HttpFoundation\RedirectResponse;
use Symfony\Component\HttpFoundation\BinaryFileResponse;

// HTML page
return $this->renderTwig('my_plugin/page.twig', ['title' => 'Hello']);

// JSON API
return $this->json(['status' => 'ok', 'data' => $items]);

// Redirect
return $this->redirect('/dashboard');

// Permanent redirect
return $this->redirect('/new-url', 301);

// Raw string
return $this->render('<h1>Hello</h1>', 200);

// Custom response
return new Response('Not Allowed', 405, ['Allow' => 'GET, POST']);

Flash Messages

Use Message to pass status messages across redirects. They are stored in $_SESSION and consumed on the next request.

use Simp\Pindrop\Message\Message;

// Set messages before redirecting
Message::info('Settings saved successfully');
Message::warn('Some fields were skipped');
Message::error('Failed to save — please try again');

return $this->redirect('/admin/settings');

In your Twig template, call Message::send() to retrieve and clear them:

{% set messages = message_send() %}
{% for msg in messages %}
  <div class="alert alert-{{ msg.type }}">{{ msg.text }}</div>
{% endfor %}

Generating URLs

use Simp\Pindrop\Routing\Url;

// By route name
$url = Url::routeByName('admin.users.edit', ['user_id' => 42]);
// → /admin/users/42/edit

// Absolute URL
$abs = Url::routeByName('admin.dashboard', [], absolute: true);
// → https://example.com/admin

// Current URL with extra query params
$cur = Url::current(['page' => 2]);

// By raw path
$path = Url::routeByUri('/user/[user_id:int]', ['user_id' => 5]);
Best practice

Keep controllers thin. Move business logic into service classes registered in services.yml and injected through the DI container. Controllers should only orchestrate: read input → call service → return response.
