Welcome to Pindrop CMS

Pindrop CMS is a modular, developer-first content management system designed for flexibility, scalability, and clean architecture.

Core Idea:
The core system stays minimal, while features are added through independent plugins.

🚀 What is Pindrop?

Pindrop is built around a plugin-based architecture where functionality is not hardcoded into the core system.

Instead of a monolithic CMS, Pindrop allows you to:

  • Add features as plugins
  • Enable or disable functionality easily
  • Keep the core system clean and maintainable
  • Scale your application without complexity
Think of Pindrop as a core engine + modular extensions.

🧩 Plugin-Based Architecture

Every feature in Pindrop is delivered as a plugin.

  • Admin panels
  • Payment systems
  • Analytics tools
  • Custom business logic

Plugins are:

  • Independent
  • Replaceable
  • Version-controlled via Git branches

🌿 How Plugins Work

Plugins are stored in a central repository where:

  • Each branch represents one plugin
  • The branch name = plugin name

After downloading, plugins are placed in:

modules/<plugin-name>

⚙️ Enabling Plugins

Plugins are controlled via configuration:

config/sync/core.plugin.yml

Example: 

admin: 1
payments: 0
  • 1 → Installed and enabled
  • 0 → Installed but disabled

🧠 Philosophy

Pindrop follows modern development principles:

  • Modularity — Everything is a plugin
  • Separation of concerns — Core vs features
  • Developer control — No hidden magic
  • Scalability — Grow without rewriting
Pindrop gives developers full control over system behavior without sacrificing simplicity.

📦 Getting Started

  • Browse available plugins
  • Download from repository branches
  • Place in modules/
  • Enable via config

Continue to the Plugins section to install your first plugin.
